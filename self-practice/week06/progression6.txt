คุณสมบัติของ Closure function ใน JavaScript
    - การมีหน้าตาเหมือน nested functions
    - การอ้างถึง scope ของ ตัวแปรที่อยู่ใน function ได้เท่านั้น (outer / global ได้)
    - ต้อง return function ที่เป็น nested ออกไป (เพราะถ้าไม่ทำ อาจจะทำให้ภายนอกเรียก function ไม่ได้)
    - โดยที่ outer ต้อง return closure ออกไป -> ไม่งั้นจะเรียก closure จากภายนอกไม่ได้
    - รักษาสภาพแวดล้อมทั้งหมดของ function
    - closure function คือ function ที่รักษา state ของตัวแปรต่างๆ ที่เกี่ยวข้องด้วย

Deep inspection of Closure function

function outer() {
    const name = 'Pongsatorn';
    return function inner() {
        console.log('Outer name :', name)
    }
}
const res = outer();
res();

code returns -> Outer name : Pongsatorn
    - จาก code นี้จะเห็นได้ว่า การเรียก function outer() จะออกเป็นค่าของ function inner() ที่ดึง value ของ variable ที่อยู่ระดับ global ไปใช้งาน

closure function = stateful หรือ การเรียก function แบบมีสถานะได้
function createAdd(a) {
  return function(b) {
    return a + b;
  };
}

const addFive = createAdd(5);
const addTen = createAdd(10);

console.log(addFive(10)); // 15
console.log(addTen(10));  // 20

โดยที่ 
	•	createAdd(5) จะจำค่า a = 5 เอาไว้ภายใน closure
	•	createAdd(10) จะจำค่า a = 10 แยกกันเป็นคนละ instance
	•	แต่ละตัวเป็น “ฟังก์ชันที่จำ state ของตัวเองได้”
